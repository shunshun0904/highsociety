# 学習パイプライン

`index.html` の CPU（本気）が使う方策ネットワークを、自己対戦の強化学習で作るための一式です。
Node.js だけで動きます（外部パッケージなし）。

## 設計の要点

**ゲームのコードを二重に持たない。** 学習側は `index.html` の `ENGINE_START`〜`ENGINE_END` と
`AGENT_START`〜`AGENT_END` の2区画をそのまま切り出して実行します（`harness.js`）。
特徴量の作り方も候補手の作り方も本番と同一のコードなので、学習した方策と
ブラウザで動く方策がずれることが構造的に起こりません。

**行動空間。** 入札は「手札の部分集合」なので組合せが多すぎます。そこで
「いまの最高額 + d を超える最小の組合せ」を d = 1,2,3,5,8,13,21,34 について作り、
これに「降りる」を足した9択に畳んでいます（`agentActions`）。
部分和は動的計画法で一度に表にするので、候補手の生成は1手あたり約1200演算で済みます。

**特徴量（91次元）。** 場のカード、残り山札の内訳（＝全員が見て分かる公開情報）、
自分の小切手の内訳・獲得済みカード・得点、競りの状況、他3人の残金と持ち札、
そして「いま終われば自分が最下位脱落か」といった位置取り。詳細は `index.html` の
`agentFeatures`。

**報酬。** 終局時にのみ与えます。勝ち＝1（同点は山分け）を 0.85、順位を 0.15 の
配分で混ぜたもの。順位を少し混ぜるのは、勝ち負けだけだと信号が疎すぎて
学習の立ち上がりが遅いためです。

**学習法。** PPO（クリップ 0.2）＋ 価値関数の同時学習。相手席は
現在の自分 70% / 過去の自分 20% / 既存の思考ルーチン 10% で混ぜています。
過去の自分を混ぜるのは方策の堂々巡りを防ぐため、既存CPUを混ぜるのは
自己対戦だけで通用する奇妙な均衡に落ちるのを防ぐためです。

## 使い方

```sh
node train/selftest.js    # 部分和DP・候補手・特徴量・対局ループの健全性チェック
node train/train.js       # 自己対戦で学習（既定 260反復・約45分・4コア想定）
node train/export.js      # train/weights.json を int8 量子化して index.html に埋め込む
node train/verify.js      # 埋め込み後の強さを実測する
```

主なオプション（`node train/train.js --iters=260 --games=768 --lr=0.0005 ...`）:

| 引数 | 既定 | 意味 |
|---|---|---|
| `--iters` | 260 | 反復回数 |
| `--games` | 768 | 1反復あたりの自己対戦局数 |
| `--workers` | 3 | 対戦を回すワーカースレッド数 |
| `--epochs` / `--mb` | 3 / 1024 | PPOの学習エポックとミニバッチ |
| `--lr` / `--lrEnd` | 5e-4 / 1e-4 | 学習率（線形に減衰） |
| `--ent` / `--entEnd` | 0.02 / 0.004 | エントロピー係数（線形に減衰） |
| `--pCpu` / `--pPool` | 0.10 / 0.20 | 相手席に既存CPU／過去の自分を混ぜる割合 |
| `--evalEvery` | 20 | 何反復ごとに既存CPUと対戦評価するか |
| `--init` | なし | 続きから学習する。`embedded` で `index.html` の埋め込み済み重みから、パス指定で `train/weights.json` から |

学習率は 3e-4 / 6e-4 / 1.2e-3 を20反復ずつ比べ、1.2e-3 は明確に崩れたため
5e-4 から 1e-4 へ減衰させる設定にしています。

## ファイル

| ファイル | 役割 |
|---|---|
| `harness.js` | `index.html` から ENGINE / AGENT 区画を切り出して Node で動かす |
| `game.js` | 1局を進めて学習サンプルと報酬を取り出す |
| `net.js` | 方策ネットワークの順伝播・逆伝播・Adam・PPO更新 |
| `worker.js` | 自己対戦をワーカースレッドで並列に回す |
| `train.js` | 学習の本体 |
| `evaluate.js` | 席順を回しながらの対戦評価（互角なら勝率0.25） |
| `export.js` | 重みを int8 量子化して `index.html` に埋め込む |
| `verify.js` | 埋め込み後の強さを実測する |
| `selftest.js` | ロジックの健全性チェック |
| `weights.json` | 学習した重み（float32・リポジトリには含めない） |
