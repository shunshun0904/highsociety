# ハイソサエティ

ライナー・クニツィアのボードゲーム「ハイソサエティ (High Society)」をブラウザで遊べるようにした、単一HTMLファイルのアプリです。

- 4人対戦（あなた + CPU 3名）
- ルールは Osprey Games 2018年版 公式ルールブックに準拠
- 外部依存なし。`index.html` を開くだけで動作します
- CPU は**自己対戦の深層強化学習（PPO）で鍛えた方策ネットワーク＋先読み**

## 遊ぶ

GitHub Pages で公開しています。

タイトル画面で対戦相手を選べます。

- **ハード（AI）** ── 学習した方策＋先読み。残金の位置取りと終幕までの残り枚数を見て、押せば降りるかどうかを読んでから競ってきます
- **イージー（AI）** ── 従来の手書き思考ルーチン

## CPU について

学習AIは `index.html` に**埋め込まれた重みだけで動きます**（推論も素のJavaScript、通信もライブラリも無し）。

| | |
|---|---|
| 入力 | 91次元（場のカード／残り山札の内訳／自分の小切手と獲得札／競りの状況／他3人の状態／脱落圏かどうか） |
| ネットワーク | 全結合 96(ReLU) → 64(ReLU) → 9行動 + 状態価値 |
| 行動 | 「降りる」＋「最高額 + d を超える最小の小切手の組合せ」8通り（d = 1,2,3,5,8,13 と 残金の25%・50%） |
| 学習 | 自己対戦 PPO ＋ GAE。報酬は終局の勝敗を主とし、競りごとの位置取りの差を中間報酬に割り振る |
| 先読み | 候補手ごとに局面を複製して打ってみて、2手先の価値で比べる（1手あたり6ms） |
| 重み | int8量子化 + Base64 で約 20KB |

**先読み**が効きます。方策は「一目で決める」ので、押せば相手が降りるのか返り討ちに
遭うのかを確かめていません。そこで候補手ごとに局面を複製して実際に打ってみて、
自分の判断2回ぶん先まで進めた地点の価値を比べます。複製した局面では山札を必ず
切り直すので、伏せられた順序を覗くことはありません。

学習と実行で**同じコードが動くこと**を構造で保証しています。学習スクリプトはゲームエンジンと
特徴量抽出を `index.html` の該当区画からそのまま切り出して実行するので、
学習した方策とブラウザで動く方策がずれません。詳細は [`train/README.md`](train/README.md)。

### 強さ

4人ゲームなので**互角なら勝率 0.250** です。席順は1局ごとに回して有利不利を消しています。

| 対戦 | 勝率 |
|---|---|
| **方策＋先読み 1人 vs 既存CPU 3人** | **0.621** |
| 方策のみ 1人 vs 既存CPU 3人 | 0.554 |
| 方策＋先読み 1人 vs 方策のみ 3人 | 0.464 |
| 方策のみ 1人 vs 方策＋先読み 3人 | 0.164 |
| 方策＋先読み 1人 vs 乱択 3人 | 0.835 |
| ［参考］既存CPU 1人 vs 乱択 3人 | 0.772 |

学習だけで 0.250 → 0.554、そこに**先読みを載せて 0.621** です。
先読みは互角の相手（自分自身）にも 0.464 とほぼ倍の勝率で、
逆に先読み3人に囲まれた素の方策は 0.164 まで落ちます。

学習の推移（20反復ごと、対 既存CPU3人）:

```
反復  20    40    60    80   100   120   140   160   180   200   220   240   260
勝率 .247  .353  .429  .446  .476  .484  .507  .513  .537  .528  .536  .543  .550
```

**量子化の影響はありません。** int8化した重みと元の float32 を直接戦わせて 0.255（互角）。

**温度（方策のやわらかさ）は効きません。** 収束した方策は十分に尖っており、
温度0.1〜1.0の勝率差は誤差の範囲でした（0.534〜0.557）。同じ局面でいつも同じ手を
打たないほうが対戦相手として自然なので 0.85 を採用しています。

**伸ばそうとして駄目だった方向**（学習量を増やす／網を大きくする／先読みを方策に
教え込む）も実測つきで [`train/README.md`](train/README.md) に残してあります。

### 学習をやり直す

Node.js だけで動きます（外部パッケージ不要）。

```sh
node train/selftest.js    # ロジックと先読みの安全性の検査
node train/train.js       # 自己対戦で学習（約45分／4コア想定）
node train/export.js      # 重みを index.html に埋め込む
node train/verify.js      # 埋め込み後の強さを実測
node train/demo.js        # 学習AI同士の棋譜を1局分表示
node train/league.js     # リーグ戦で延々と鍛える（勝ち抜き戦で王座を更新）
```
