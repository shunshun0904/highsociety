# ハイソサエティ

ライナー・クニツィアのボードゲーム「ハイソサエティ (High Society)」をブラウザで遊べるようにした、単一HTMLファイルのアプリです。

- 4人対戦（あなた + CPU 3名）
- ルールは Osprey Games 2018年版 公式ルールブックに準拠
- 外部依存なし。`index.html` を開くだけで動作します
- CPU は**自己対戦の深層強化学習（PPO）で鍛えた方策ネットワーク**

## 遊ぶ

GitHub Pages で公開しています。

タイトル画面で対戦相手を選べます。

- **本気** ── 自己対戦で学習した方策ネットワーク。残金の位置取りと終幕までの残り枚数を見て競ってきます
- **ひかえめ** ── 従来の手書き思考ルーチン

## CPU について

学習AIは `index.html` に**埋め込まれた重みだけで動きます**（推論も素のJavaScript、通信もライブラリも無し）。

| | |
|---|---|
| 入力 | 91次元（場のカード／残り山札の内訳／自分の小切手と獲得札／競りの状況／他3人の状態／脱落圏かどうか） |
| ネットワーク | 全結合 96(ReLU) → 64(ReLU) → 9行動 + 状態価値 |
| 行動 | 「降りる」＋「最高額 + d を超える最小の小切手の組合せ」8通り（d = 1,2,3,5,8,13,21,34） |
| 学習 | 自己対戦 PPO。報酬は終局時のみ（勝ち 0.85 ＋ 順位 0.15） |
| 重み | int8量子化 + Base64 で約 20KB |

学習と実行で**同じコードが動くこと**を構造で保証しています。学習スクリプトはゲームエンジンと
特徴量抽出を `index.html` の該当区画からそのまま切り出して実行するので、
学習した方策とブラウザで動く方策がずれません。詳細は [`train/README.md`](train/README.md)。

### 学習をやり直す

Node.js だけで動きます（外部パッケージ不要）。

```sh
node train/selftest.js    # ロジックの健全性チェック
node train/train.js       # 自己対戦で学習（約45分／4コア想定）
node train/export.js      # 重みを index.html に埋め込む
node train/verify.js      # 埋め込み後の強さを実測
node train/demo.js        # 学習AI同士の棋譜を1局分表示
```
